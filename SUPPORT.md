# Support

## How to file issues and get help

This project uses [GitHub issues][gh-issue] to [track bugs][gh-bug] and [feature requests][gh-feature]. Please search the existing issues before filing new issues to avoid duplicates. For new topics, file your bug or feature request as a new issue.

For questions about using this project, please look at our [Contributor's Guide][contributor] if you want to work on Mantle.

## Microsoft Support Policy

Support for this project is limited to the resources listed above.

[gh-bug]: https://github.com/microsoft/azure-container-linux/issues/new?labels=bug
[gh-feature]: https://github.com/microsoft/azure-container-linux/issues/new?labels=enhancement
